# 학급 참여 코드 4자리 변경 — 2026-10-13

사용자 요청에 따라 기존 Firebase `math3-dev`, Worker `math3-cp3-dev`, GitHub Pages 서비스에 숫자 4자리 코드를 적용한다. Google 연결과 학습 원장은 그대로 유지한다.

- 새 학급은 `0000`–`9999`를 균등하게 발급한다. 이미 예약된 코드는 재사용하지 않으며 충돌 시 최대 16번 재시도한다. 앞자리 0과 전각 숫자를 처리한다.
- 기존 학급은 소유 교사가 해당 학급을 열 때 `ensureClassJoinCode`로 전환한다. 같은 학급의 동시 요청은 같은 코드로 수렴한다. 기존 코드 인덱스와 버전은 유지하므로 이전 8자리 코드도 원래 30일 만료일까지 유효하다.
- 변경 전 암호문과 코드 인덱스 식별자를 `joinCodeBackups`에 원자적으로 기록한다. 학생, 승인 대기, 학습 기록, Google 설정을 변경하지 않는다. 승인 대기 학생이 새 코드로 다시 신청해도 중복 신청을 만들지 않는다.
- 인증·소유권·교사 승인·기존 속도 제한과 Firestore 직접 접근 거부를 유지한다. 짧은 코드는 참여 신청을 위한 것으로 접근 권한을 부여하지 않는다.

배포 전 기존 30개 학급과 30개 코드의 Firestore 문서를 Git 제외 `.cp5-test-artifacts/join-code-20261013/before.json`에 저장했다. 기존 Worker 버전은 `ca7fbc93-8732-4a84-9b9e-764d6473d14f`다. 이전 버전은 숫자 코드를 지원하지 않으므로 새 숫자 학급이 생긴 뒤에는 그 버전으로 단순 롤백하지 않고 호환 버전으로 수정 배포한다. 특정 기존 학급의 표시 코드를 복원해야 할 때는 백업 암호문을 해당 classId에만 복원하고 새 인덱스를 비활성화하는 변경안을 먼저 확인한다. 인덱스나 기록을 삭제하지 않는다.

숫자 코드 공간은 10,000개이며 현재 예약된 코드를 자동 회수하지 않는다. 전체 공간 소진에 가까워지면 별도 운영 정책이 필요하다. 이번 변경은 기존 코드의 30일 만료 정책을 변경하지 않는다.

검증: 단위·보안 50개(중복 재시도, 앞자리 0, 전각 숫자, 잘못된 코드 거부, 소유권, 동시 전환, 구 코드 호환 포함), Chromium 교사 기존 학급 전환 및 Sheets 회귀. 배포 및 공개 검증 결과는 완료 후 기록한다.
