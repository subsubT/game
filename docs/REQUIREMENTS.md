## 2. 학생 진입과 신원

1. `1math3.html`에 접속해 ‘학급 참여’ 또는 ‘혼자 연습’을 선택한다. 계정 입력이나 Google 로그인은 없다.
2. 학급 참여 시 백그라운드 Firebase 익명 인증 → 학급코드 입력 → 개인 구분용 이름/별명(선택, 교사에게만 표시) → 참여 신청.
3. 서버가 ‘초록별-27’ 같은 학급 별명과 2자리 확인 표식을 발급한다. 교사는 교실에서 표식을 대조해 개별/선택 일괄 승인한다. 승인 전에는 다른 학생·학급명·순위·명단을 보여주지 않고 연습만 허용한다.
4. 승인된 브라우저는 다시 입력하지 않고 같은 studentId를 사용한다. 브라우저 데이터 삭제·새 기기는 교사가 기존 학생에 대해 발급한 10분 유효 일회용 복귀 QR/코드로 연결한다. 이름 입력만으로 기존 학생을 선택하게 하지 않는다.
5. 공용 기기에는 ‘학생 바꾸기’를 항상 제공한다. 해당 학습 세션·임시 결과·화면 정보를 지우고 인증을 종료한다. 다음 학생은 자기 복귀 코드 또는 새 참여 승인 절차를 거친다.

이름/별명은 최대 12 Unicode 문자, NFC 정규화, 앞뒤 공백 제거, 제어문자 금지, DOM에는 텍스트로 출력한다. 실명·연락처 입력을 권하지 않는다. 이름 중복은 허용하고 studentId로 구분한다. 학급 별명은 서버 사전 조합이며 학생 자유입력을 공개하지 않는다. 교사는 자기 학급의 이름/별명 대응을 볼 수 있다.

‘혼자 연습’은 이름·학급·서버 저장 없이 시작한다. 학급 순위는 학급 참여 후 사용할 수 있음을 안내하며 두 순위 탭 자체는 숨기지 않는다. 전체 순위는 온라인 인증이 가능한 경우 최소 공개 데이터만 조회한다. 연습 결과는 순위에 반영되지 않는다.

## 3. 핵심 게임 규칙: rulesVersion `1.0.0`

| 항목 | 확정 규칙 |
|---|---|
| 정규 회차 | 50문항, 5유형×10, 교육과정 문서의 10라운드 고정 배치. 10·20·30·40번째 문항 뒤 선택 쉬어가기 제공 |
| 시간 | 교육용 제한시간 없음. 소요시간은 본인·교사용 참고값이고 순위에 사용하지 않음. 서버 회차는 24시간 후 만료 |
| 채점 | 문항 최초 응답 정답 10점, 오답·건너뛰기 0점, 총 0~500점. 감점·연속정답 가산점 없음 |
| 다단계 | 10 만들고 더하기는 쌍 선택과 합 모두 처음 맞아야 10점. 단계별 기록은 진단용 |
| 오답 피드백 | 정답과 구체물 풀이 제시. ‘다음’ 버튼으로 진행하며 읽기 전 자동 전환하지 않음 |
| 건너뛰기 | 버튼으로 확정하면 해당 문항 0점·해설 제공. 무응답과 구분 |
| 보상 | 맞힐 때 별 1개, 총 최대 50개. 회차를 마치면 점수와 관계없이 완주 표시. 유료·확률형·등수별 독점 보상 없음 |
| 완료 | 50문항 모두 응답 또는 건너뛰기 → 결과. 전부 건너뛰어도 완료 0점 |
| 직접 종료 | 확인 후 현재까지 결과 저장. 미완료 회차로 분리하며 순위 제외 |
| 브라우저 종료 | 서버 회차의 마지막 확정 위치에서 24시간 이내 이어 하기. 클라이언트에만 있던 응답은 미확정으로 안내 |
| 재도전 | 새 sessionId·새 문제 seed. 이전 회차 덮어쓰기 없음. 최고점만 순위 대표로 사용 |
| 연습 | 유형 선택 또는 동일 50문항, 도움·복습 허용. 공식 순위 제외 |

정답 수 C, 오답 W, 건너뛰기 K, 미응답 U에 대해 회차 전체는 `C+W+K+U=50`, 유형별로는 `C+W+K+U=10`, `score=10*C`이다. 정답률은 `C/(C+W)`로 표시하되 분모가 0이면 ‘아직 답한 문제가 없어요’. 교사에게는 별도로 완료율 `(C+W+K)/50`, 유형별 완료율 `(C+W+K)/10`을 표시한다. 50문항을 끝낸 뒤 복습하여 맞힌 답은 원점수를 바꾸지 않는다.

## 4. 화면 및 상태 흐름

`entry → joining/pending → ready → starting → playing ↔ feedback → finishing → result → review/retry`

- 시작: 현재 학급 별명·게임 제목·50문항·전체 순위 기본 등록 및 해제 안내·연습/기록 도전 선택.
- 게임: 현재 문항/50, 별, 큰 문제·구체물·숫자 입력. 10·20·30·40번째 문항 뒤 선택 쉬어가기 화면을 제공하고 50번째 뒤 결과로 간다. 순위는 접을 수 있는 별도 탭으로 제공하여 풀이 영역을 가리지 않는다.
- 결과: 점수·최초 정답/오답/건너뛰기·저장 상태·다시 풀기·복습·두 순위 탭.
- 서버 채점은 문항 확정 단위로 진행. 제출 중 입력 잠금. 응답이 불확실하면 같은 요청 ID로 다시 확인하고 임의로 다음 문항을 열지 않는다.
- 네트워크가 끊기면 현재 문항 상태를 보존해 재전송하거나 ‘연습으로 계속’을 선택한다. 연습 전환 후 답은 서버 공식 회차에 합치지 않으며 원회차는 미완료로 종료한다.
- `saveStatus`: `localOnly / pending / confirmed / failed`. 결과 저장 성공과 순위 집계 상태 `pending / ready / excluded`를 구분한다.
- 새로고침은 서버 세션을 조회해 복원한다. 24시간 만료는 미완료 종료이며 새 회차를 안내한다. 만료 전 제출 여부는 서버 수신시간으로 정한다.
- 접근권한 상실·학급 폐쇄 시 상세 응답을 제거하고 연습 진입을 제공한다.

## 5. 순위와 표시

`boardKey = gameId + rulesVersion + curriculumVersion + seasonId`이며 `seasonId`는 회차 시작 시각의 KST 월 `YYYY-MM`. 다음 달에 완료해도 24시간 이내라면 시작 월에 속한다. 순위 제목에 게임·평가 버전·월을 표시한다.

| 구분 | 표시 | 비공개 |
|---|---|---|
| 우리 반 | 해당 학급의 별명, 최고점, 공동 순위, 본인 강조 | 실명, 다른 학생의 오답·세부시간·식별 ID |
| 전체 | 게임·월별 별도 자동 별명, 최고점, 공동 순위, 본인 강조 | 학급 별명, 학교·학급명·코드, 교사, 학생 ID, 이름, 상세 수행 |
| 본인 결과 | 현재 회차와 본인 최고점, 문항 복습 | 다른 학생 데이터 |
| 교사 | 자기 학급의 이름/별명 대응, 회차·유형·문항 수행 | 다른 교사의 학급 및 개인정보 |

서버 검증된 정규 완료 회차만 대상. 같은 학급의 같은 studentId당 최고점 1행, 전체도 학급 소속 studentId당 1행이다. 다른 기기에서 동일 studentId로 복귀하면 합쳐진다. 다른 학급에 새로 등록한 사람은 별개 참여자이며 전국 단위 개인 실명 인증·중복 사람 판별은 하지 않는다. ‘전체 순위’는 이 서비스의 참여 기록 순위이며 공인 성취도 비교가 아니다.

점수 내림차순. 같은 점수는 공동 순위 `1,1,3`. 동점 표시 순서는 공개 행 키로 안정화하며 시간·재도전 횟수로 우열을 가르지 않는다. 한 페이지 최대 50행, 전체 최초 TOP 50 + 본인 점수/공동 순위, 다음 페이지 커서. 동점 집단이 페이지를 넘을 수 있으며 각 행의 순위는 동일하다. 낮은 점수 재도전은 최고점을 내리지 않는다.

전체 순위 별명은 학급 별명과 독립적으로 생성하고 게임·월마다 바꾼다. 공개 행 키에도 내부 식별자를 넣지 않는다. **전체 순위 등록은 기본 켜짐**이다. 학급 생성 시 교사 설정과 학생 승인 시 학생 설정을 모두 켜짐으로 생성하며, 정규 회차 완료 시 두 설정이 켜져 있으면 별도 신청 없이 최고 기록을 전체 순위에 반영한다. 시작 화면에서 이 기본 동작과 독립 별명 사용을 알린다. 교사 또는 학생이 자기 범위의 **등록**을 끄면 전체 노출을 해제하고, 꺼도 두 순위 **조회**는 유지한다. 설정 변경 후 이전 공개 행도 제거한다. 다시 켜면 해당 월의 기존 유효 최고점을 재집계한다.

## 6. 교사 흐름과 대시보드

`교사용 시작 → 로그인 없이 시작 → 관리 공간 생성 → 복구 키 보관 확인 → 학급 생성 → 참여코드 발급 → 학생 승인 → 학습·결과 관리`

- 관리 공간: Google 없이 이용, 기존 복구 키로 되찾기, 선택 Google 연결. Google을 연결해도 동일 teacherId·학급을 유지한다.
- 학급 목록: 학급명(비공개), 참여 상태, 최근 활동. 학급 생성·이름 변경·보관·삭제.
- 학급 관리: 코드 표시/복사·회전·참여 열기/닫기, 대기 학생 표식 확인/승인/거절, 학생 별명·선택 이름 수정, 복귀 코드 발급, 등록 취소·삭제.
- 게임 결과: gameId·월·기간·학생·완료 상태 필터, 최초 정답률·완료율·유형별 수행. 미응답을 오답과 섞지 않는다. 문항 상세는 클릭 시 필요한 회차만 조회.
- 순위 설정: 학급 순위 확인, 기본 활성화된 전체 등록의 해제/재활성화, 공개 행 삭제 요청. 전체 학생의 상세정보를 보는 기능은 없다.
- 소유권: 복구 키 재발급, 기기 권한 해제, Google 연결 상태. 공유 기기는 잠금/로그아웃 제공.
- Sheets: 연결 안 함/연결됨/재승인 필요/생성 중/동기화 오류 상태. 자동 생성, 앱에서 만든 기존 문서 선택, 문서 열기, 동기화, 연결 해제. URL·ID 직접 입력 금지.

상세 화면은 교사 인증과 현재 소유권을 서버가 확인한 뒤 데이터를 반환한다. `?board=1` 같은 URL 옵션으로 교사 권한을 얻을 수 없다.

## 7. Checkpoint 구분

Checkpoint 1은 이 계약과 아키텍처 확정까지다. Checkpoint 2는 교육과정 문서의 생성기·채점·학생 화면·복습·모의 저장 및 모의 순위 계약을 구현한다. 실제 교사 대시보드, Firebase, Google OAuth, Sheets, Apps Script, 최종 배포는 별도 후속 단계다. Checkpoint 2에서 모의 데이터를 실제 학급 기록처럼 표시하지 않는다.
