# 즉시 가입 및 교사 학생 관리 — 2026-10-13

사용자 요청으로 기존 `math3-dev` / `math3-cp3-dev` / GitHub Pages에서 교사 승인 절차를 제거한다. 별도 환경이나 데이터 이전은 없다.

유효한 4자리 코드(기존 8자리도 원래 만료까지 호환)를 입력하면 `requestJoin`이 학생 문서와 활성 소속 바인딩을 한 트랜잭션으로 만든다. 재시도·동시 요청은 같은 학생을 반환하며, 이미 소속된 학생의 이름을 가입 재시도로 덮어쓰지 않는다. 다른 학급으로 임의 이동할 수 없다. 기존 승인 대기 학생은 다음 `getStudentStatus` 조회나 코드 재입력에서 기존 식별자·이름·별명을 유지하고 자동 활성화한다. 변경 전 문서를 백업한다. 내부 응답 `approved`는 기존 클라이언트와 호환하는 활성 소속 상태 이름이다. 과거 승인 API는 호환용으로 보존하지만 화면과 새 흐름에서는 사용하지 않는다.

교사의 학생 목록에는 ‘이름 변경’과 ‘학생 삭제’를 제공한다. 이름 변경은 1~12자, 공백만/제어 문자 거부, HTML 이스케이프를 적용하며 서버 소유권을 검사한다. 학생의 비공개 이름만 변경하며, 공개 순위·Sheets의 별명과 학습 점수는 바꾸지 않는다. 학생 화면도 다음 접속이나 기록 시작 시 서버 이름을 읽는다.

학생 삭제는 해당 학생을 `removed`로 표시하고 현재 바인딩을 비활성화한다. 학급·전체 순위 행을 제거하고 점수별 인원도 함께 갱신한다. 학습 원장은 삭제하지 않으며 `studentAdminBackups`에 소속·학생·순위·집계의 변경 전 자료를 보관한다. 같은 기기의 삭제된 소속으로 코드 재입력, 기존 기록 조회·제출, 복귀 티켓 사용을 할 수 없다. 다른 익명 기기를 동일 인물로 판별하는 기능은 없다. 교사 화면의 현재 학생/회차와 다음 Sheets 동기화에서도 삭제 학생은 제외한다. 연결된 관리표에 갱신 작업을 예약한다. 기존 학생·수업 데이터의 자동 일괄 삭제는 하지 않는다.

학생 가입 방식만 사용자 요청대로 변경하며 Firebase 인증, 코드 유효성/만료/속도 제한, 교사 소유권, 타인 학급/기록 격리, Firestore 브라우저 직접 접근 거부는 유지한다. 이름 변경·삭제는 요청 ID로 멱등성을 확인한다. 게임 시작·제출·완료 트랜잭션도 학생의 활성 상태와 UID를 다시 확인하여 삭제/기기 이전과 겹친 요청의 오래된 권한 사용을 거부한다.
